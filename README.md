# Sales Management · Grupo 2 · Sesión 12

**UAM · MAR0411 · Miércoles 4 de noviembre de 2026**  
**Tema:** Marketing directo, segmentación y diseño de campañas orientadas al cliente.  
**Duración de la presentación:** 44 diapositivas · 159 minutos.

Presentación interactiva preparada para usarse en clase. Incluye una introducción histórica, conceptos clave, ejemplos de campañas, decisiones de canal, ejercicios, un diccionario, una práctica de diseño y un calculador de indicadores.

## Uso

- Abrir la página publicada en GitHub Pages para iniciar la presentación.
- Navegar con las flechas izquierda y derecha; `Inicio` y `Fin` saltan a la primera y última diapositiva.
- El botón **Presentar** activa pantalla completa. **Índice**, **Diccionario** y **Notas** ayudan a recorrer y facilitar la clase.
- La comprobación interactiva incluida funciona dentro de la presentación y no se registra en el libro de calificaciones.

Los casos y perfiles de práctica son ejemplos didácticos. Las referencias citadas dentro de la presentación abren sus fuentes originales.

## Fuente

El archivo `index.html` contiene estilos, contenido y JavaScript en una sola página, sin dependencias externas para mostrar la clase.
